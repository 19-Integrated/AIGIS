# AIGIS: AI Governance Infrastructure Stack

AIGIS is a modular, constitutional architecture for AI governance. It consists of:
- A **Core** (mandatory) — the non-negotiable constitutional foundation
- **Optional Modules** — extensible components for compliance, security, and governance depth

## Core (Mandatory)
- ICC-9
- HOF
- HAN
- HIS-12
- AICA-5
- ADTEP
- IMP
- AWOF
- Trigger System

## Optional Modules
- **Regulatory Compliance Overlays**: EU AI Act, NIST AI RMF, Philippines, (Singapore, China)
- **Security Modules**: AEGIS, Zero Trust, MCP Governance, Supply Chain, Skills
- **Governance Depth**: Board-Level, Systemic Risk, Remediation
- **Integration**: AI OSI, Real-time Streaming
- **Human Factors**: The Shadow, VGDF
- **Operations**: CEF, EAF, ILTP, CGF, ERDP, DEP

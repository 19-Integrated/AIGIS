# CIS v2.0 — Contestation Interface Standard (CIS)

**Status:** Built — v2.0 (Reconciliation with ICC-8 I8, ERDP, IMP, AICA-5, HAN/HOF, and DEP)  
**Type:** Constitutional Instrument  
**Parent Stack:** ICC-8 (Intelligence Constitutional Charter) — I8 External Legibility Invariance  
**Version:** 2.0 — Supersedes CEN-1 to CEN-6 v1.0

---

## PREAMBLE

The Contestation Interface Standard (CEN-1 to CEN-7) defines the standards for external contestation — the mechanisms through which institutional actions are externally legible, auditable, and contestable. It answers: *How does an external party interpret, question, or contest a material institutional action?*

CEN-1 to CEN-7 are the operational implementation of ICC-8 I8 External Legibility Invariance. They ensure that every material institutional action is mappable to an external interpretation path — satisfying the constitutional requirement that an institution cannot be internally coherent and externally unaccountable.

**The core insight:** An institution that satisfies all internal governance requirements but cannot be interpreted, audited, or contested from outside fails the legitimacy condition. CEN-1 to CEN-7 close that gap by making every material action externally legible and contestable through defined, accessible pathways.

---

## SECTION 1: PURPOSE AND SCOPE

### Purpose

CEN-1 to CEN-7 ensure that:

1. **Actions are interpretable** — External parties can understand material actions without internal access  
2. **Contestation is accessible** — Defined pathways exist for external parties to raise objections  
3. **Traceability is maintained** — Contestation connects to the audit chain (I3)  
4. **Confidentiality is protected** — Restricted information is handled by independent review  
5. **Independence is preserved** — Contestation authority is structurally separate from action authority  
6. **Redress is provided** — Valid contestation findings produce corrective pathways  
7. **Public contestation is enabled** — Non-institutional stakeholders have a voice (CEN-7)

### Scope

| In Scope | Out of Scope |
| :---- | :---- |
| External interpretation of institutional actions | Internal operational appeals |
| Contestation pathways for external parties | Business strategy or marketing |
| Confidentiality protection for restricted information | Operational efficiency |
| Structural independence of contestation authority | Technical delivery execution |
| Redress and remediation pathways | Internal governance disputes |
| Public contestation for non-institutional stakeholders | Commercial disputes |

### Governing Relationships

| Instrument | Relationship to CEN-1 to CEN-7 |
| :---- | :---- |
| **ICC-8** | Constitutional parent — I8 External Legibility Invariance |
| **ERDP** | Disclosure and reporting — ERDP operationalizes CEN requirements |
| **IMP** | Contestation records logged as OEO, DRO, GAO, XOO |
| **AICA-5** | Rollback pathways (Ac-N4) referenced for redress |
| **HAN/HOF** | HAN is escalation endpoint for contestation |
| **DEP** | CEN amendments require DEP process |

## SECTION 2: CEN-1 — INTERPRETABILITY

### Statement

Any material institutional action must be describable in terms intelligible to an external party without access to internal systems or proprietary doctrine.

### Requirements

| Requirement | Description |
| :---- | :---- |
| **Plain Language** | Actions are described in plain language, not proprietary jargon |
| **Context** | Actions are described with sufficient context for external understanding |
| **No Internal Access Required** | Interpretation does not require access to internal systems or proprietary doctrine |
| **Documentation** | Interpretation documentation is maintained as a Disclosure Record |

### Implementation

| Aspect | Implementation |
| :---- | :---- |
| **AIR and QOU** | Annual Institutional Report and Quarterly Operational Update use plain language |
| **Disclosure Records** | Disclosure Records provide contextual descriptions |
| **Public Designation Register** | Designation status described in plain language |
| **CEN-1 Violation** | Material action with no external interpretation path |

### CEN-1 Failure Response

| Failure | Response |
| :---- | :---- |
| **No External Interpretation Path** | Action flagged; HAN notified; XOO created |
| **Proprietary Jargon Only** | Action flagged; Disclosure Record revised |
| **Internal Access Required** | Action flagged; interpretation path created |

## SECTION 3: CEN-2 — ACCESSIBILITY

### Statement

A defined pathway must exist through which external parties — regulators, affected stakeholders, DFI counterparties — may raise questions, objections, or audit requests against material institutional actions.

### Requirements

| Requirement | Description |
| :---- | :---- |
| **Defined Pathway** | A clear, documented pathway exists for contestation |
| **Accessibility** | The pathway is accessible to defined external parties |
| **No Barriers** | No unnecessary barriers to raising objections |
| **Documentation** | Pathway documentation is publicly available |

### Implementation

| Aspect | Implementation |
| :---- | :---- |
| **Contestation Submission** | Defined process for submitting contestation |
| **Public Designation Register** | Public verification pathway |
| **Tier Elevation Protocol** | DFI/sovereign access pathway |
| **CEN-7 Public Contestation** | Non-institutional stakeholder pathway |
| **CEN-2 Violation** | Contestation pathway inaccessible to defined external parties |

### CEN-2 Failure Response

| Failure | Response |
| :---- | :---- |
| **No Defined Pathway** | Pathway created; HAN notified |
| **Pathway Inaccessible** | Accessibility barriers removed; HAN notified |
| **Pathway Undocumented** | Documentation created and published |

## SECTION 5: CEN-4 — CONFIDENTIALITY PROTOCOL

### Statement

Where a valid contest involves I6-restricted information, that information is not disclosed to the contesting party. An independent review node — structurally separate from both the originating authority and the contesting party — is granted full access and renders a finding. The contesting party receives the finding.

### Requirements

| Requirement | Description |
| :---- | :---- |
| **No Disclosure to Contesting Party** | Restricted information is not disclosed to the contesting party |
| **Independent Review Node** | Independent review node has full access |
| **Structural Independence** | Review node is structurally separate from originating authority |
| **Finding to Contesting Party** | Contesting party receives the finding (not the underlying information) |

### Implementation

| Aspect | Implementation |
| :---- | :---- |
| **Independent Review Node** | F-OV agent from non-originating entity (cross-review under AWOF v1.1 Section 12\) |
| **Structural Independence** | Review node has no voting/blocking capacity in originating authority |
| **Finding Disclosure** | Contesting party receives finding, not underlying information |
| **CEN-4 Violation** | Restricted information disclosed to contesting party; independent review node without structural independence |

### CEN-4 Failure Response

| Failure | Response |
| :---- | :---- |
| **Restricted Information Disclosed** | Immediate containment; HAN notified; XOO created |
| **No Independent Review Node** | Independent review node appointed; HAN notified |
| **Structural Independence Violated** | Review node replaced; HAN notified |

## SECTION 6: CEN-5 — INDEPENDENCE

### Statement

The contestation node must not be administered by any party that holds voting or blocking capacity in the originating authority. The originating authority may hold observation rights in contestation proceedings. Decision rights in contestation are prohibited for the originating authority.

### Requirements

| Requirement | Description |
| :---- | :---- |
| **No Voting/Blocking Capacity** | Originating authority has no voting or blocking capacity in contestation |
| **Observation Rights Only** | Originating authority may hold observation rights |
| **Decision Rights Prohibited** | Decision rights in contestation are prohibited for originating authority |

### Implementation

| Aspect | Implementation |
| :---- | :---- |
| **Structural Separation** | Contestation node structurally separate from originating authority |
| **Observation Rights** | HAN may observe but not decide contestation proceedings |
| **Decision Rights** | Decision rights held by Accountability layer (H9–H12) or independent review node |
| **CEN-5 Violation** | Originating authority holding voting/blocking rights in contestation |

### CEN-5 Failure Response

| Failure | Response |
| :---- | :---- |
| **Originating Authority Has Voting Rights** | Voting rights removed; HAN notified |
| **Originating Authority Has Blocking Rights** | Blocking rights removed; HAN notified |
| **Decision Rights Not Prohibited** | Decision rights reassigned; HAN notified |

## SECTION 7: CEN-6 — REDRESS AND REMEDIATION

### Statement

A valid contestation finding must produce a defined corrective pathway. Corrective actions, including rollbacks via AICA-5 Ac-N4, are treated as proposed actions subject to CFL-V incremental verification and I7 continuity impact assessment before confirmation. Redress is not automatic.

### Requirements

| Requirement | Description |
| :---- | :---- |
| **Defined Corrective Pathway** | Valid contestation findings produce a defined corrective pathway |
| **CFL-V Verification** | Corrective actions subject to CFL-V incremental verification |
| **I7 Continuity Impact Assessment** | Corrective actions subject to I7 continuity impact assessment |
| **Redress Not Automatic** | Redress is not automatic — it is a proposed action subject to verification |

### Implementation

| Aspect | Implementation |
| :---- | :---- |
| **Corrective Action Taxonomy** | Defined taxonomy of corrective actions |
| **CFL-V Verification** | Corrective actions pass CFL-V incremental verification |
| **I7 Continuity Impact Assessment** | Continuity impact assessed before confirmation |
| **Rollback Pathways** | AICA-5 Ac-N4 rollback pathways referenced |
| **CEN-6 Violation** | Corrective action without continuity impact assessment |

### CEN-6 Failure Response

| Failure | Response |
| :---- | :---- |
| **No Defined Corrective Pathway** | Corrective pathway defined; HAN notified |
| **No CFL-V Verification** | CFL-V verification initiated; action held |
| **No I7 Continuity Impact Assessment** | Continuity impact assessment initiated; action held |
| **Redress Automatic** | Process corrected; HAN notified |

## SECTION 8: CEN-7 — PUBLIC CONTESTATION

### Statement

Any individual may submit a governance concern regarding AI actions affecting them. Submission is logged as OEO (`outcome_type: public_contestation`). 19 Integrated has 30 days to review and respond. Response is logged as GAO (`artifact_type: contestation_response`). If unresolved, escalates to HAN.

### Requirements

| Requirement | Description |
| :---- | :---- |
| **Individual Access** | Any individual may submit a governance concern |
| **OEO Logging** | Submission logged as OEO (`outcome_type: public_contestation`) |
| **Review Timeline** | 30 days to review and respond |
| **Response Logging** | Response logged as GAO (`artifact_type: contestation_response`) |
| **HAN Escalation** | If unresolved, escalates to HAN |

### Implementation

| Aspect | Implementation |
| :---- | :---- |
| **Public Submission Interface** | Accessible web interface for public contestation |
| **OEO Logging** | Submission logged as OEO in IMP |
| **Review Process** | 30-day review and response window |
| **GAO Response** | Response logged as GAO in IMP |
| **HAN Escalation** | Unresolved contestation escalates to HAN |
| **CEN-7 Violation** | No public contestation pathway; unresolved contestation not escalated to HAN |

### CEN-7 Failure Response

| Failure | Response |
| :---- | :---- |
| **No Public Submission Interface** | Interface created; HAN notified |
| **No OEO Logging** | OEO created; HAN notified |
| **Review Timeline Exceeded** | HAN notified; escalation initiated |
| **No GAO Response** | GAO created; HAN notified |
| **Unresolved Not Escalated** | Escalation to HAN initiated |

## SECTION 9: CONTESTATION LIFECYCLE

### Lifecycle States

| State | Description | Transitions |
| :---- | :---- | :---- |
| **Submitted** | Contestation submitted by external party | → Under Review / Rejected |
| **Under Review** | Contestation under review | → Finding Issued / Escalated |
| **Finding Issued** | Finding issued by review node | → Corrective Action Proposed / Rejected |
| **Corrective Action Proposed** | Corrective action proposed | → Corrective Action Confirmed / Rejected |
| **Corrective Action Confirmed** | Corrective action confirmed and executed | → Resolved |
| **Resolved** | Contestation resolved | — (terminal state) |
| **Rejected** | Contestation rejected | — (terminal state) |
| **Escalated** | Contestation escalated to HAN | → Finding Issued / Resolved |

### Lifecycle Transitions

Submitted  
  │  
  ├──→ Under Review (contestation accepted)  
  │       │  
  │       ├──→ Finding Issued (review complete)  
  │       │       │  
  │       │       ├──→ Corrective Action Proposed (valid finding)  
  │       │       │       │  
  │       │       │       ├──→ Corrective Action Confirmed (verified)  
  │       │       │       │       │  
  │       │       │       │       └──→ Resolved  
  │       │       │       │  
  │       │       │       └──→ Rejected (not verified)  
  │       │       │  
  │       │       └──→ Rejected (finding invalid)  
  │       │  
  │       └──→ Escalated (escalated to HAN)  
  │               │  
  │               ├──→ Finding Issued  
  │               │       │  
  │               │       └──→ Resolved  
  │               │  
  │               └──→ Resolved  
  │  
  └──→ Rejected (contestation rejected at submission)

### Contestation Rules

| Rule | Description |
| :---- | :---- |
| **Defined Pathway** | CEN-1 to CEN-7 provide defined contestation pathways |
| **Due Process** | Contestation follows due process |
| **IMP Logging** | All contestation events are logged in IMP |
| **HAN Escalation** | Unresolved contestation escalates to HAN |
| **Periodicity** | Periodic disclosure cycle independent of contestation |

## SECTION 10: PERIODICITY

### Requirement

External legibility is not event-triggered only. Every derived charter must define a minimum periodic disclosure cycle through which material institutional actions are reported to defined external parties independent of active contestation.

### Implementation

| Aspect | Implementation |
| :---- | :---- |
| **Annual Institutional Report (AIR)** | Annual periodic disclosure |
| **Quarterly Operational Update (QOU)** | Quarterly periodic disclosure |
| **Public Designation Register** | Continuous public disclosure |
| **CEN Violation** | Absence of periodic disclosure cycle |
